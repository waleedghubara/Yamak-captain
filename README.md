# Yamak Captain

Yamak Captain is an Expo and React Native app for Yamak drivers.

## Requirements

- Node.js 20 or newer
- npm

## Setup

```bash
npm ci
npm start
```

The app's Expo and Codemagic build configuration is in `app.config.ts` and
`codemagic.yaml`. iOS build and upload notes are in [README-iOS.md](./README-iOS.md).

Do not commit local environment files, signing credentials, or App Store review
login details.
